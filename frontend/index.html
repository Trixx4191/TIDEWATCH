SCIENTIFIC METHODOLOGY
Elevation Model
NASA SRTM v3.0 — 30m DEM from Space Shuttle radar (2000). Void-filled, reprojected to WGS84.
Inundation Model
Flood-fill bathtub: pixel inundated if elevation ≤ surge + SLR AND hydrologically connected to ocean via BFS from coastline.
Sea Level Rise
IPCC AR6 Table 9.9 intermediate (SSP2-4.5): +0.30m by 2050, +0.56m by 2075, +1.01m by 2100.
Flood Equity Index
FEI = (% inundated low-income land) ÷ (% low-income tracts) × 100. Source: ACS B19013, HUD 80% AMI definition.
SST Anomaly
MODIS Level-3 deviation from 1985–2012 baseline. Anomaly >+0.5°C correlates with intensification (Emanuel 1987).
Limitation
Bathtub model omits wave dynamics and time-dependent surge. For evacuation planning, use NOAA SLOSH or ADCIRC.
